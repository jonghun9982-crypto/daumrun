# 다음런

달리기 기록·계획·코스 추천 웹앱 (아이폰 홈 화면 앱 지원)

| 탭 | 기능 |
|---|---|
| 오늘 | 오늘의 운동 계획, 이번 주 일정, 달리기 시작 |
| 달리기 | GPS 실시간 기록, 일시정지·재시작, 코스 따라가기 |
| 코스 | 주변 공원·강변길 기반 순환 코스 추천 (3/5/10km) |
| 기록·플랜 | 달 기록, 달력, RPE·통증 채크인, 월별 캘린더 |
| AI 코치 | 규칙 기반 대화형 코치 (통증·회복 안내) |
| 설정 | 프로필, 운동 요일, 계획 일시정지 |

- 최초 설정에서 현재 수준·목표·달릴 수 있는 요일을 알려주면 규칙 기반으로 오늘의 운동 유형과 시간을 정해 줘요.
- 달리는 동안 GPS로 거리·시간·페이스를 기록하고 화면 꺼지지 않도록 기기 잠금 방지를 사용해요.
- 코스 추천은 OpenStreetMap 기반으로 주변 공원·산책로를 지나는 순환 경로를 만들어 줘요. 고도 정보도 함께 표시해요.
- 모든 기록과 설정은 이 기기(localStorage)에만 저장됩니다. 서버로 보내지 않아요.
- 가슴 통증이나 위험 증상이 기록되면 자동으로 계획을 조정하거나 일시정지해요. 진단이나 의료 조언은 하지 않습니다.
